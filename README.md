# UrbanCOmpanyHomePage ASP.NET Razor Pages

UrbanCompanyHomePage is a responsive homepage inspired by Urban Company, built using ASP.NET Razor Pages (Visual Studio).

## Features

* Responsive modern UI
* Hero section
* Services section
* Offer cards
* Google Fonts
* Google Material Icons

## Technologies Used

* ASP.NET Razor Pages
* HTML5
* CSS3

## File Structure

```text
Pages/
 └── Index.cshtml
```

## Run the Project

```bash
dotnet restore
dotnet watch run
```

```text
Pages/Index.cshtml
```
